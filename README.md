# Вебзастосунок для аналізу та рекомендацій покращення програмного коду

Кваліфікаційна робота на здобуття першого (бакалаврського) рівня вищої освіти за спеціальністю 121 «Інженерія програмного забезпечення».

## Опис проекту
Програмна система для автоматизованого статичного аналізу коду, виявлення структурних антипатернів, міжкласових залежностей та надання рекомендацій щодо оптимізації і рефакторингу програмного забезпечення з генерацією тестів.

## Структура проекту
- `backend/` — серверна частина (Java 21, Spring Boot 3, Spring Data JPA, PostgreSQL)
- `frontend/` — клієнтський веб-інтерфейс (React, TypeScript, Vite, Monaco Editor)
- `docs/` — технічна документація, діаграми та матеріали кваліфікаційної роботи

## Вимоги до середовища
- Java 21+
- Node.js 18+
- PostgreSQL 15+
- Docker & Docker Compose (опціонально для контейнеризації)
